# Yifeng Yu —Personal academic GitHub Pages website of Yifeng Yu, Professor of Mathematics at UC Irvine.

Files:
- `index.html` — main faculty page
- `publications.html` — publications
- `courses.html` — course landing page
- `math210a.html` — Math 210A, Fall 2026
- `math210b.html` — Math 210B, Winter 2027

## Publish with GitHub Pages
1. Create a GitHub repository (for example, `yifengyu.github.io`).
2. Upload all files in this folder to the repository root.
3. In **Settings → Pages**, deploy from the main branch/root folder.
4. GitHub will publish the site at the corresponding GitHub Pages URL.
